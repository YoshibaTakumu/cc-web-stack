# cc-web-stack とは

[English](README.md) | 日本語

cc-web-stack は、エージェントが読んで実行するためのメタリポジトリです。宿主の利用者の環境にある既存のリポジトリ、または新しく作るリポジトリを、Claude Code が完全に自律して運用できるリポジトリへ作り上げます。

## 目的

Claude Code に作業を任せるとき、人はその都度、規約・検証の手順・触ってよい範囲・過去の判断を補っています。cc-web-stack は、それらを対象のリポジトリ自身に持たせます。

ここでいう「完全に自律して運用できる」とは、次の状態を指します。

- エージェントが、作業の受け取りから実装・検証・レビュー・取り込みまでを、人の補足なしに進められる。
- 人が行うのは、方針の決定と、人の承認が必要と定めた判断だけである。

## 対象

- **読み手**: Claude Code。人はエージェントに、このリポジトリを読ませて対象のリポジトリを指示するだけにする。
- **対象のリポジトリ**: 宿主の環境にある既存のリポジトリ、または新しく作るリポジトリ。

## 提供するもの

- **導入の手順**: エージェントが対象のリポジトリを診断し、足りないものを足す手順。既存のリポジトリでは、今ある規約と検査を壊さずに足す。
- **エージェントの入口**: `AGENTS.md` / `CLAUDE.md` から、作業に必要な規約・手順へたどれる構成。
- **規約**: 命名・型・スキーマ・エラー・コメントの規約。
- **機械的な検査**: 規約を文書ではなく検査で守らせる仕組み（lint の独自ルールとラッパー、型検査、依存の方向、テスト）。
- **実行時の制御**: Claude Code の hooks と権限の設定。
- **完了の基準**: どの検証を通せば「完了」と報告してよいかの定義。

## 提供しないもの

- 対象のリポジトリのアプリの機能そのもの。
- 人の承認が必要な判断の代行（破壊的な操作、外部への公開、検査の無効化など）。
